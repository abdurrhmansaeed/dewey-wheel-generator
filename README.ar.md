# مولّد دائرة تصنيف ديوي العشري

**العربية** | [English](README.md)

أداة تعمل في المتصفح لإنشاء **دائرة تصنيف ديوي العشري** بصيغة **SVG** نظيفة وقابلة للتحرير. تعمل الأداة بالكامل على جهاز المستخدم: تعدّل البيانات، تختار الخطوط والألوان، تعاين الدائرة ثم تصدّرها.

الواجهة متعددة اللغات، وكل لغة في ملف JSON بسيط، فيمكن لأي شخص إضافة لغة جديدة دون تعديل الكود. يضم المشروع العربية (RTL) والإنجليزية (LTR).

## المزايا

- إنشاء دائرة التصنيفات الرئيسة والفرعية من بيانات نصية بسيطة.
- تحكم كامل بالخطوط وأحجامها والألوان (النصوص والخلفيات والدوائر والفواصل).
- اتجاهان لأرقام الدائرة الداخلية: موحّد أو مقروء دائمًا.
- تصدير SVG باسم مخصص أو اسم تلقائي بالتاريخ والوقت.
- واجهة متعددة اللغات تدعم RTL وLTR، ولكل لغة أرقامها وخطوطها وبياناتها النموذجية.
- بلا أدوات بناء ولا أطر عمل: ملف HTML واحد مع ملفات اللغة JSON.

## التشغيل السريع

تحمّل الصفحة ملفات اللغة بـ `fetch`، لذا يجب تشغيلها عبر HTTP (أغلب المتصفحات تمنع ذلك عند فتحها مباشرة بـ `file://`).

```bash
git clone https://github.com/<your-user>/<repository-name>.git
cd <repository-name>
python -m http.server 8000
```

افتح <http://localhost:8000>. استبدل `<your-user>` باسم مستخدمك في GitHub و`<repository-name>` باسم المستودع.

للنشر باستخدام **GitHub Pages**، اختر *Settings ← Pages ← Deploy from a branch ← `main` / root*. سيعرض GitHub Pages الملف `index.html` تلقائيًا.

إن تعذّر تحميل مجلد `lang/` تعرض الصفحة زرًا لاختيار ملفات اللغة يدويًا.

> يلزم اتصال بالإنترنت لتحميل خطوط Google ومكتبة jQuery.

يمكن فتح لغة محددة بإضافة `?lang=en` إلى الرابط. وإلا يُستخدم آخر اختيار محفوظ في المتصفح، ثم اللغة التي فيها `"is_default": true`.

## صيغة البيانات

كل كتلة تمثل تصنيفًا رئيسًا، وتُفصل الكتل بسطر فيه `###`.

```text
الديانات = 200-299
الدين الإسلامي = 210
الكتاب المقدس = 220
الدين المسيحي = 230-280
###
العلوم الاجتماعية = 300-399
الإحصاءات = 310
```

- **أول سطر** في الكتلة هو التصنيف الرئيس، وبقية الأسطر تصنيفات فرعية.
- العلامة `=` تفصل العنوان عن الرقم (يُعتمد آخر `=` في السطر).
- تُحوَّل الأرقام تلقائيًا إلى مجموعة أرقام اللغة المختارة.
- ضع `$` داخل العنوان الفرعي لتقسيمه إلى سطرين يتوسطهما الرقم، مثل: `الفلسفات القديمة-$الوسيطة والشرقية = 180`.

## مصدر البيانات

بيانات تصنيف ديوي العربية الموجودة في `examples/data-text/` متاحة ضمن النطاق العام، وهي منقولة من الكتاب:

> *مختصر التصنيف في المكتبات ونظام ديوي العشري*، منشورات وزارة الثقافة-مديرية المراكز الثقافية، دمشق، 2011م.

والكتاب مختصر لعمل باللغة العربية حول تصنيف ديوي العشري نشرته المنظمة العربية للتربية والثقافة والعلوم (ألكسو). «تصنيف ديوي العشري» علامة تجارية مسجلة لمنظمة OCLC؛ هذا المشروع مستقل وغير تابع للمنظمة ولا معتمد منها.

## ملفات اللغة

```
lang/
├─ index.json   # قائمة ملفات اللغة المطلوب تحميلها
├─ ar.json
└─ en.json
```

الملف `lang/index.json` مصفوفة بسيطة: `["ar.json", "en.json"]`.

بنية ملف اللغة:

| المفتاح | الوصف |
|---|---|
| `code` | رمز اللغة مثل `en`، ويُستخدم في `?lang=` وفي وسم `lang` للصفحة. |
| `name` | اسم اللغة بلغتها كما يظهر في قائمة الاختيار. |
| `dir` | اتجاه النص: `"rtl"` أو `"ltr"`. |
| `is_default` | `true` للغة الافتراضية (يوضع في ملف **واحد** فقط). |
| `digits` | الأرقام العشرة للإخراج، مثل `"0123456789"` أو `"٠١٢٣٤٥٦٧٨٩"`. |
| `fonts` | أسماء الخطوط في قائمة الخطوط. |
| `fonts_url` | رابط Google Fonts لهذه الخطوط (اختياري). |
| `font_fallback` | قائمة الخطوط الاحتياطية المكتوبة في ملف SVG المصدَّر. |
| `metrics.fit` | متوسط عرض الحرف نسبةً إلى حجم الخط لتصغير النص حتى يتسع (≈ `0.35` للعربية، ≈ `0.55` للاتينية). |
| `metrics.wrap` | معامل العرض الذي يحدد متى يُقسَّم العنوان إلى سطرين. |
| `metrics.sub_wrap_below` | إذا احتاج العنوان الفرعي إلى خط أصغر من هذا الحجم قُسّم تلقائيًا إلى سطرين (`0` يعطّله). |
| `center_text` | النص الافتراضي في مركز الدائرة. |
| `ui` | جميع نصوص الواجهة (انظر `lang/en.json` لقائمة المفاتيح كاملة). |
| `default_data` | البيانات النموذجية، وكل سطر عنصر في المصفوفة. |

أي مفتاح ناقص يُؤخذ من اللغة الافتراضية.

### إضافة لغة جديدة

1. انسخ `lang/en.json` إلى `lang/<code>.json` (مثل `fr.json`).
2. ترجم `name` و`ui` و`center_text` و`default_data`، واضبط `dir` و`digits` و`fonts` و`metrics`، وأبقِ `is_default` بقيمة `false`.
3. أضف اسم الملف إلى `lang/index.json`.
4. أعد تحميل الصفحة واختر اللغة وافحص الدائرة الناتجة، وعدّل `metrics` إن فاضت العناوين.

التفاصيل في [CONTRIBUTING.md](CONTRIBUTING.md).
