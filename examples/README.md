# Examples

- `data-text/` contains public-domain Arabic Dewey classification data reproduced from *مختصر التصنيف في المكتبات ونظام ديوي العشري* (Publications of the Ministry of Culture – Directorate of Cultural Centers, Damascus, 2011).
- `svg/` contains exported SVG wheels.
- `png-96dpi/` contains PNG previews rendered at 96 DPI.

See the root [README](../README.md) for the full source citation and project licensing note.
